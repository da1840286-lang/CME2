# CME2 — минимальные финальные исправления

Эта сборка основана на переданном рабочем архиве. Архитектура и состав этапов не расширялись. Layer 3 не добавлялся.

## Что исправлено

1. **Product FIND по умолчанию** использует целевой Sponsored Search: точное название оффера, затем ключевые слова оператора, затем тип/категорию товара (не более трёх запросов). Старый Ads Top-путь остаётся только для явной диагностики через `performance_plan="legacy_ads_top"`.
2. **Branding contract v2** восстановлен как единый контракт: режим выбирается только в workflow menu, эффективные разрешённые марки входят в OfferCard fingerprint и manifest, Frame проверяет совпадение.
3. **Проверка действий в source evidence** больше не принимает прилагательное `clear` в выражении `clear silicone bag` за действие очистки. Проверка противоречия сопоставляет конкретные действия, а не только общие существительные.
4. **Механизм** считается перенесённым только при наличии соответствующего MUST image atom. QA-only атом не подменяет визуальное требование генерации.
5. **Target evidence** — каждая запись должна быть одним непрерывным дословным фрагментом одного поля OfferCard. Склейка нескольких claims, перефразирование и усиление спецификации блокируются.
6. **Mechanism admission** требует явный положительный `query_product_match.matches=true` и непустой `query_anchor`. Отсутствующее или неопределённое подтверждение блокируется.
